# Zoom Auto Recorder

指定した時刻に Zoom 会議へ自動で参加し、Windows の画面と PC の音声を録画する Windows 用ツールです。

- 招待URL、またはミーティングID＋パスコードと開始時刻を入れて予約
- 時刻になると Zoom を起動し、「参加」やオーディオ接続のボタンを自動で押して入室
- カメラ・マイクのオン/オフを予約ごとに指定
- 入室後に会議画面を全画面表示にしてから録画を開始（参加前の画面や待機室は録画しません）
- 会議が終わると録画を止めて mp4 で保存（予定より早く終わった場合も、その時点で停止）

> [!IMPORTANT]
> **録画する前に、ホストと参加者の同意を得てください。**
> このツールは Zoom の録画機能ではなく、画面を外から録画します。そのため、他の参加者に「録画中」の表示は出ません。
> 同意のない録画や、録画の無断共有は、所属先のルールや法令に反する場合があります。利用は自己責任でお願いします。

## 動作環境
- Windows 10 / 11
- Python 3.10 以上（インストール時に「Add python.exe to PATH」にチェック）
- Zoom デスクトップアプリ（Zoom Workplace）
- ffmpeg（`setup.bat` が winget で自動インストールします）

## インストール
1. このリポジトリをダウンロード（緑の「Code」→「Download ZIP」）して展開
2. `setup.bat` をダブルクリック（Python パッケージと ffmpeg を入れます）
3. `run.bat` をダブルクリックでアプリ起動

## 使い方
1. 「予約」タブで、招待URL（例 `https://us02web.zoom.us/j/12345678901?pwd=xxxx`）
   または ミーティングID＋パスコードを入力
2. 開始日時を入力（`2026-10-12 10:00`、`10/12 10:00`、`10:00` のいずれか。`10:00` だけなら今日、過ぎていれば明日）
3. カメラ・マイクのオン/オフを選ぶ（既定値は「設定」タブで変更可）
4. 「予約に追加」。すぐ試すなら「今すぐ参加して録画」

予約時刻になると、次の順に動きます。
Zoom を起動 → 参加ボタン等を自動で押す → 入室を確認 → 全画面表示 → 録画開始 → カメラ・マイクを設定 → 会議終了を検知して停止・保存

一覧の行をダブルクリックすると、録画ファイルが開きます。

### 録画が止まる条件
- 会議が終わった（会議ウィンドウが閉じてから15秒後。「ホストによって終了されました」が出たら即時）
- 最大録画時間に到達（予約ごとに指定。既定180分）
- 「録画を停止」ボタン

入室できないまま一定時間（既定30分）が過ぎた場合は、録画せずに終了します。

### 注意
- 予約を実行するには、**アプリを開いたままに**してください。
- 予約がある間はスリープと画面オフを防ぎますが、**画面がロックされると真っ黒に録画されます**。
- 画面全体を録画するため、録画中に出たデスクトップ通知なども映ります。
- 録音するのは**既定の再生デバイス**の音です。
- 自動操作の際に、マウスカーソルが動いたり Zoom の画面が前面に出たりします。

## 設定タブ
| 項目 | 説明 |
|---|---|
| 保存先フォルダ | 既定は `ビデオ\ZoomRecordings` |
| 予約時の既定 | 予約フォームのカメラ・マイクの初期値 |
| 録画範囲 | メインモニター／全モニター |
| 参加後に全画面にする | 画面共有などで解除された場合も自動で戻します |
| フレームレート・CRF | 既定 15fps・CRF 28（画質を上げるなら CRF 23 前後） |
| 音声の補正 | 映像と音がずれる場合に秒単位で調整 |
| 10秒テスト録画 | 画面と音が録れるかの確認用 |
| 会議中かチェック | 会議中と判定できるか、カメラ/マイクの状態を読めるかの確認用 |
| Zoomの画面要素を書き出す | Zoom のボタン名をテキストに書き出します（不具合調査用） |

## うまく動かないとき
ボタンの自動クリックは、Zoom のボタン名（日本語・英語）を手がかりにしています。Zoom のバージョンや表示言語によって
名前が違うと、うまく動かないことがあります。その場合は、問題の画面を出した状態で「Zoomの画面要素を書き出す」を押し、
できたテキストを添えて Issue を立ててください（会議名や参加者名が含まれる場合は消してから貼ってください）。

ログ・設定・予約は `%APPDATA%\ZoomAutoRecorder\` に保存されます。パスコードはここに平文で保存されるので注意してください。

## 仕組み
| ファイル | 役割 |
|---|---|
| `app.py` | 画面（tkinter）、予約管理、実行制御 |
| `zoom_control.py` | 招待URLの解析、`zoommtg://` での Zoom 起動、会議ウィンドウの検出、全画面化 |
| `zoom_ui.py` | UI Automation（pywinauto）による参加ボタン等のクリック、カメラ/マイクの切り替え |
| `recorder.py` | ffmpeg（gdigrab）での画面録画、WASAPI ループバックでの PC 音声録音、mp4 への結合 |
