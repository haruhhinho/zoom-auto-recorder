# Zoom Auto Recorder

指定した時刻に Zoom 会議へ自動で参加し、Windows の画面と PC の音声を録画する Windows 用ツールです。

- 招待URL、またはミーティングID＋パスコードと開始時刻を入れて予約
- 時刻になると Zoom を起動し、「参加」やオーディオ接続のボタンを自動で押して入室
- カメラ・マイクのオン/オフを予約ごとに指定
- 入室後に会議画面を全画面表示にしてから録画を開始（参加前の画面や待機室は録画しません）
- 会議が終わると録画を止めて mp4 で保存（予定より早く終わった場合も、その時点で停止）
- 曜日を選ぶだけの繰り返し予約（回数や最終日も指定可）、予約の編集・複製
- 画面に重なる参加者の映像の小窓を自動で最小化
- 文字の大きさを4段階で変更可能
- 会議中のチャットに流れた URL を既定のブラウザで自動で開く（会議後もブラウザは開いたまま）
- チャットで共有されたファイル（PDF、Word・Excel・PowerPoint など）を自動でダウンロードし、録画の横にまとめる

> [!IMPORTANT]
> **録画する前に、ホストと参加者の同意を得てください。**
> このツールは Zoom の録画機能ではなく、画面を外から録画します。そのため、他の参加者に「録画中」の表示は出ません。
> 同意のない録画や、録画の無断共有は、所属先のルールや法令に反する場合があります。利用は自己責任でお願いします。

## 動作環境
- Windows 10 / 11
- Python 3.10 以上（インストール時に「Add python.exe to PATH」にチェック）
- Zoom デスクトップアプリ（Zoom Workplace）
- ffmpeg（`setup.bat` が winget で自動インストールします）

## インストール
1. このリポジトリをダウンロード（緑の「Code」→「Download ZIP」）して展開
2. `setup.bat` をダブルクリック（Python パッケージと ffmpeg を入れます）
3. `run.bat` をダブルクリックでアプリ起動

## 使い方
1. 「予約」タブで、招待URL（例 `https://us02web.zoom.us/j/12345678901?pwd=xxxx`）を貼り付けるか、
   ミーティングIDとパスコードを入力
2. 開始日時を入力
3. カメラ・マイクのオン/オフを選ぶ
4. 定例の会議なら「繰り返し」をオンにして、曜日にチェック（毎日なら月〜日、平日なら月〜金）
5. 「繰り返し方」を選ぶ：ずっと／回数で（例 10回）／最終日を指定（その日も含む）
6. 「録画日」に、録画が始まる日付が表示されるので確認する（繰り返しなら、選んだ曜日の日付だけが並びます）
7. 「予約に追加」。すぐ試すなら「今すぐ参加して録画」

文字が小さくて見にくい場合は、右上の「文字の大きさ」で 小／標準／大／特大 を選べます（次回起動時も保持）。

入力欄は数字だけ打てば、区切りが自動で入ります。入力欄の右側には、入力した内容がどう読み取られたかが表示されます。

| 欄 | 入力 | 表示 |
|---|---|---|
| ミーティングID | `12345678901` | `123 4567 8901`（9桁・10桁の ID も桁数に合わせて区切ります） |
| 開始日時 | `202610211000` | `2026-10-21 10:00` → 右側に「10月21日（水）10:00」 |
| 繰り返しの最終日 | `20261225` | `2026-12-25` |

パスコードに空白が入っていた場合は、自動で取り除きます。表示名・カメラ・マイク・最大録画時間は、前回の入力が次の予約の初期値になります。

### 予約の編集・複製・削除
一覧で予約を選び、下のボタンを押します。
- **編集**：「予約中」の予約をフォームに読み込みます。直して「変更を保存」を押します（ダブルクリックでも可）
- **複製**：どの予約でもフォームに読み込みます。日時などを直して「予約に追加」を押すと、別の予約になります
- **削除**：繰り返し予約を削除すると、今後の回もすべて実行されなくなります

繰り返し予約は、実行のたびにその回の記録が一覧に追加され、予約は自動で次回の日時に進みます。
回数や最終日を指定した場合は、最後の回が終わると「繰り返し終了」になります。
PC が止まっていて開始時刻を10分以上過ぎた回は「期限切れ」として記録され、次回に進みます。

予約時刻になると、次の順に動きます。
Zoom を起動 → 参加ボタン等を自動で押す → 入室を確認 → 全画面表示 → 録画開始 → カメラ・マイクを設定 → 会議終了を検知して停止・保存

一覧の行をダブルクリックすると、録画ファイルが開きます。

### 会議中のチャット（URL・ファイル）
チャットを読み取るため、入室後にチャット欄を自動で開きます（Alt+H）。チャット欄は録画にも映ります。
- **URL**：チャットに流れた URL を、既定のブラウザで開きます。録画が隠れないよう、開いた後は Zoom を前面に戻します。
  ブラウザは会議後も開いたままです。入室時にすでにチャットにあった URL も開きます。
  Zoom 自身のリンク（zoom.us など）は、開くと今の会議から抜けてしまうため開きません。
- **ファイル**：チャットのファイルの「ダウンロード」を自動で押します。
  会議が終わると、会議中に「ドキュメント\Zoom」と「ダウンロード」フォルダに保存されたファイルを、
  録画ファイルの横の「〜_資料」フォルダにコピーしてまとめます（元のファイルはそのまま残ります）。
  ブラウザで開いたリンクからダウンロードされたファイルも、ここにまとまります。

> [!WARNING]
> チャットの URL は、誰が送ったものでも自動で開きます。知らない人が参加する会議では、
> 「設定」タブの「会議中のチャット」で URL・ファイルの自動処理をオフにしてください。

### 録画が止まる条件
- 会議が終わった（会議ウィンドウが閉じてから15秒後。「ホストによって終了されました」が出たら即時）
- 最大録画時間に到達（予約ごとに指定。既定180分）
- 「録画を停止」ボタン

入室できないまま一定時間（既定30分）が過ぎた場合は、録画せずに終了します。

### 注意
- 予約を実行するには、**アプリを開いたままに**してください。
- 予約がある間はスリープと画面オフを防ぎますが、**画面がロックされると真っ黒に録画されます**。
- 画面全体を録画するため、録画中に出たデスクトップ通知なども映ります。
- 録音するのは**既定の再生デバイス**の音です。
- 自動操作の際に、マウスカーソルが動いたり Zoom の画面が前面に出たりします。

## 設定タブ
| 項目 | 説明 |
|---|---|
| 保存先フォルダ | 既定は `ビデオ\ZoomRecordings` |
| 録画範囲 | メインモニター／全モニター |
| 参加後に全画面にする | 画面共有などで解除された場合も自動で戻します |
| 参加者の映像の小窓を最小化 | 画面共有中などに会議画面の上に重なる映像の小窓を隠します |
| 会議中のチャット | URL をブラウザで開く／ファイルをダウンロード／チャット欄を自動で開く を個別にオン・オフ |
| 資料を探す追加フォルダ | Zoom の保存先を変えている場合などに指定（`;` 区切り） |
| フレームレート・CRF | 既定 15fps・CRF 28（画質を上げるなら CRF 23 前後） |
| 音声の補正 | 映像と音がずれる場合に秒単位で調整 |
| 10秒テスト録画 | 画面と音が録れるかの確認用 |
| 会議中かチェック | 会議中と判定できるか、カメラ/マイクの状態を読めるかの確認用 |
| Zoomの画面要素を書き出す | Zoom のボタン名をテキストに書き出します（不具合調査用） |

## うまく動かないとき
ボタンの自動クリックは、Zoom のボタン名（日本語・英語）を手がかりにしています。Zoom のバージョンや表示言語によって
名前が違うと、うまく動かないことがあります。その場合は、問題の画面を出した状態で「Zoomの画面要素を書き出す」を押し、
できたテキストを添えて Issue を立ててください（会議名や参加者名が含まれる場合は消してから貼ってください）。

ログ・設定・予約は `%APPDATA%\ZoomAutoRecorder\` に保存されます。パスコードはここに平文で保存されるので注意してください。

## 仕組み
| ファイル | 役割 |
|---|---|
| `app.py` | 画面（tkinter）、予約管理、実行制御 |
| `zoom_control.py` | 招待URLの解析、`zoommtg://` での Zoom 起動、会議ウィンドウの検出、全画面化 |
| `zoom_ui.py` | UI Automation（pywinauto）による参加ボタン等のクリック、カメラ/マイクの切り替え |
| `recorder.py` | ffmpeg（gdigrab）での画面録画、WASAPI ループバックでの PC 音声録音、mp4 への結合 |
